ABOUT THE PROJECT 🌎

Smart Travel Explorer

A simple and interactive web application designed to help users discover the world.

🌍

What is Smart Travel Explorer?

Smart Travel Explorer is a web-based travel information platform that allows users to search for countries and discover useful information such as capital, population, region, currency, languages and timezone.

The website uses an online API to fetch real-time country information instead of storing all the data manually.
